# Library Management Console App

This is my first-semester Python project created for the Course Domain evaluation. It is a simple command-line program that helps manage a library catalog, track book availability, search entries, and store data persistently.

## Project Features
- Book entry management (Add titles, authors, accession IDs, and shelf locations)
- Interactive menu built for command-line navigation
- Real-time catalog search by title or author keywords
- Issue and return status toggling
- Local JSON file data persistence (`books_data.json`)

## Requirements
- Python 3.8+ installed on your system.
